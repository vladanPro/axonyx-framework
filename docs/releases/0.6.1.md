# cargo-axonyx 0.6.1 - Compiled Apps Without State Signals

CLI-only patch release. `axonyx-core`, `axonyx-runtime`, `axonyx-lsp`, and
`create-axonyx` remain at 0.6.0.

`cargo ax build --compiled` now generates a valid production binary for an
application that has backend routes and actions but no state signals. The
generated server keeps its existing patch-alias behavior, and the no-binding
path no longer emits unused-path warnings.

Upgrade the CLI with `cargo install cargo-axonyx --version 0.6.1 --force`.
Applications can keep `axonyx-runtime = "0.6.0"`.
